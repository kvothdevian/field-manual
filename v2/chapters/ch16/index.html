i.The book in execution order

Tomorrow morning you open the laptop with one page beside the keyboard: nineteen rules, every one bracketed to the session that owns it, and a blank receipt waiting for tonight. The book already decided what good looks like, fifteen times — this session turns those decisions into a single day you can repeat tired, which is exactly when you need it.

Fifteen gates, one fixed order. The stopping line [01] comes before the branch; the branch [11] before the map; the map before the pin; the pin before the fix [06]; the fix before the evidence [09]; the evidence before the commit; receipt [05/07] before sleep. The trick: each gate's output is the next gate's input, so a late evening cannot silently skip one. Ritual survives tired evenings because willpower was never a gate. Counter-weight: ritual calcifies, and a checklist that never changes starts protecting itself instead of the work — so the retro log overrides any rule at the quarterly prune [04].

Three clocks run the day, and they speak in session numbers only — zero mechanics re-explained. Morning start [01+04/11]: name the session, write the line, cut the branch. Session hygiene [01+06+09+10]: one goal, red first, evidence pasted, hatch armed. Evening review [04+05+07]: receipt filed, every claim logged ledger-style or cut. Times and tools vary; the clocks do not.

The composed arc in one paragraph: the stopping line [01] briefs the branch [11], the map [11] finds the suspect, the pin [11] names the test, the red-green [06] earns the change, the pasted output [09] proves it, the one-file commit holds the stopping line [01], and the receipt [05/07] hands off tomorrow. Seven arrows, each naming home — the timeline below doubles as the expectation for steps 2 and 5.

Where this breaks down: the ritual manufactures no judgment. Checklists filter; they do not guarantee — a green suite on a misread spec is still a misread, hence green-without-red fails the gate [09]. No receipt asserts a gate without pasted evidence; a ritual-without-run is the failure this chapter exists to kill. Novel ground with no pin to write, or a second hatch trip in one evening, both mean stop — never ritual harder.

The landing is three files in a scratch repo named ritual-run. RITUAL.md holds the nineteen bracketed rules. task.md holds one falsifiable sentence. RECEIPT.md holds command-plus-output evidence per gate plus a handoff note. Both formats are authored here — no ledger row allowed. Seventy-five minutes, opencode default, every green from your own keystrokes.

ii.The fixed order is the feature · composition over memory

Fifteen sessions of technique die the same death: remembered in the morning, abandoned by midnight. The failure is not discipline, it is architecture — fifteen separate habits compete for attention, and attention loses. Composition fixes this by collapsing fifteen decisions into one order with no branches: you never choose what comes next, you only execute what is next. A tired brain can execute; it cannot prioritize.

Each arrow carries exactly one artifact, and the artifact is the proof the next gate consumes. The stopping line is a sentence the commit later verifies against ("diff shows cart.js only"). The map is notes the blast-radius quotes. The pin is a test the red-green runs. The red is a number the receipt pastes. Break any arrow and the chapter tells you within one gate: a commit with no line to check, a fix with no red to quote, a receipt with no output to paste. The order detects its own violation — that is what makes it a ritual instead of advice.

The calcify counter is load-bearing, not decorative. A ritual that cannot change becomes superstition: rules followed because they are rules, while the work underneath moves on. So the prune is scheduled like a gate, not wished like a resolution — quarterly, from the retro log, and the log wins every argument with the page [04]. If a rule never fires in a quarter, it is cut or narrowed until it does. Nineteen rules survived this book's prune; your count will differ, and differing is the point.
