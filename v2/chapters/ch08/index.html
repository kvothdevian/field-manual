Session 08 · UI with agents · opencode default

Good UI with agents

Ship an agent-built quiz card you can defend with numbers: every pair's ratio recomputed by your own keystrokes, and a screenshot loop that halts on a sentence you wrote first.

70 min · scratch repo · needs ch04 · verified 2026-09-04

Briefing · 5 min · constrain, then measure

i.The median ships unless you forbid it

Ask an agent for a quiz card with no constraints and you get the training-data median: a dark card, slate text, rounded buttons, green-means-go feedback. It looks competent because it is the average of ten thousand competent cards. The failure is not aesthetic: nothing in the prompt forbids a 3.07:1 hint, color-only feedback, or buttons a keyboard can never reach. The median is wrong by default, because unwritten rules lose to pattern frequency. The practitioner inverse states it from the other side: agents follow existing codebase patterns closely, so a repo with no patterns gets generic output. Supply the pattern or the median ships.

Three constraint layers fix three different defaults. Tokens are named values — paper, ink, go, stop — kept in one file, so an off-palette color is not a judgment call but unwritable: the literal has nowhere legal to live. Component contracts make the compliant path the path of least resistance: buttons carry their pressed state, verdicts carry glyph plus word plus a live region, targets clear 44px by construction rather than by review. The accessibility floor is arithmetic, not taste: body pairs hold 4.5:1, large text 3:1, the book's own enhanced bar 7:1 where it claims it; meaning never rides on color alone; targets clear the 24px minimum with margin; focus stays visible; motion answers to the user's reduced-motion setting. They stack in that order: values, shapes, numbers.

Then the loop with eyes. The official prescription is a screenshot loop: hand the agent a check it can run — a test suite, a build, a screenshot compared against a design — because that check is the difference between a session you watch and one you walk away from. The UI form is explicit: take a screenshot of the result, compare it to the original, list differences, fix them. The warning rides with the prescription: a loop without acceptance criteria polishes forever, so the stop rule is written before the first screenshot. This session's halt rule names four checks and a two-cycle cap, and the loop below exits after a single genuine catch.

One honest boundary to close the briefing. Constraints scale an identity; they do not originate one. No token sheet invents taste, systems ossify around yesterday's answers, and tokens drift — this book confesses its own: the first draft of this session's sheet shipped a border token at 1.48:1, caught only because the arithmetic ran before the prose did. The discipline is noticing: write the numbers down, recompute one by hand, fix the token instead of the component.

ii.Three layers, one card · values, shapes, numbers

Tokens answer "what values exist." The format is standardized enough to interchange: name, value, type, alias — the Design Tokens Community Group's 2025.10 module, verified live 2026-09-04, still explicitly a Community Group Draft rather than a W3C Standard. In this session the sheet is eight names in one JSON file: paper, ink, muted, wash, go, stop, line, focus, plus radius and target size. The enforcement is a one-line search: after the rebuild, hex literals appear on exactly two lines — the token block itself — versus twelve scattered lines in the baseline. A literal anywhere else is not a style nit; it is a value the system cannot name, audit, or change in one place.

Contracts answer "what shapes are legal." A component library states the same idea at scale: predictable, documented pieces an agent can compose without inventing. The session's contract fits in five sentences. Buttons expose pressed state and stay disabled after a pick. Verdicts speak in three channels at once — glyph, word, and a live region — so no meaning travels by hue alone. Targets hold a 48px minimum, above both the platform 24px floor and the book's 44px bar. Focus is always drawn, 3px, at 6.70:1 against paper. Motion dies under reduced-motion. None of this is reviewed after the fact; it is built into the markup the agent is told to emit, which is what "path of least resistance" means in practice.

Arithmetic answers "prove it." Relative luminance linearizes each sRGB channel — threshold 0.04045 in the current WCAG 2.2 text, corrected from the older 0.03928 in May 2021 with no practical effect on results — weights them 0.2126 / 0.7152 / 0.0722, and the contrast ratio is lighter-plus-0.05 over darker-plus-0.05, ranging 1 to 21. The bars: 4.5:1 for body text, 3:1 for large text, 7:1 at the enhanced level. Color is never the only channel. Targets hold 24 by 24 CSS pixels minimum. Focus indicators stay visible to keyboard users. Motion triggered by interaction can be disabled. Six rows, six numbers or sentences, zero adjectives — that is the whole gate, and the session runs it by hand.

iii.Before, after, and the loop that stays honest · executed 2026-09-04

Same quiz card, two builds. The left card is agent output under a bare prompt — thirty-one lines, dark slate, confident. The right card is the token rebuild. Six decisions changed between them, and each one is checkable without opening an opinion:

BEFORE · unconstrained

What is the capital of France?

Berlin · Paris · Madrid · Rome

Feedback: button turns green or red.

AFTER · token sheet

What is the capital of France?

48px targets · pressed states · focus ring

✓ Correct — Paris · ✗ Wrong — the answer is Paris.

The six, in order: (1) eleven scattered hex literals collapse into eight named tokens, so the palette is writable in exactly one place; (2) the 3.07:1 hint becomes muted-on-paper at 7.53:1, clearing even the enhanced bar; (3) color-only feedback gains glyph, word, and live region — ✓/✗ plus text plus role=status; (4) targets hold a 48px minimum, doubling the platform floor; (5) a 3px focus ring at 6.70:1 appears where no focus style existed; (6) animation and transitions answer to prefers-reduced-motion. Cost of all six: one JSON file and a contract paragraph in the prompt. That price is the chapter's thesis in miniature.

The diff above is the loop's single catch, and it is the book's confession in miniature: the first token draft shipped a border at 1.48:1, found only because the halt rule demanded every boundary pair be measured. Borders are not text, but they are the component's edge — and an edge nobody can see is a missing control. The fix landed in tokens.json, one line, every component inheriting it. Fix the token, not the component: that sentence is worth more than the other four thousand words here.

3.Measure it

Goal: the agent reports every pair's luminance math; you recompute one ratio with node -e. Stopping condition: your keystrokes confirm at least one ratio to two decimals.

Report every text pair in index.html as fg ON bg with both relative-luminance values and the ratio. Then stop — I recompute one by hand before anything ships.

✓ Verify
  • Your terminal shows the recompute output; numbers match the agent's table exactly

⚠ If stuck

Numbers disagree in the third decimal? Check the background assumption first: undeclared backgrounds default to white per the spec's own measurement note, and a transparent wash over paper is not paper. Recompute against the rendered background, not the token name.

4.Loop with eyes, bounded

Goal: one screenshot-compare cycle against the written stop rule, max two cycles. Stopping condition: SHIP or HALT statement filed in notes.md with the four checks named.

My stop rule: pairs ≥4.5:1 · zero literals · 360px survives · focus visible. Max 2 fix cycles. Screenshot the card, list differences vs the rule, fix, re-shoot, then print SHIP or HALT with all four checks.

Loop wants a third cycle? That wanting is the failure the cap exists to catch: file HALT, name the failing check, and change the token sheet or the rule — never run an unbudgeted cycle. Browser-capture tools are optional here; resize plus Tab is the required gate, screenshots the bonus.
