## Session (5 steps)

1. Write RITUAL.md: 3 sections, every rule ends [NN]; grep-count
   verified; output-only re-prompt if agent explains.
2. Stopping line + branch: task.md one falsifiable sentence;
   reader runs git commands, pastes output into RECEIPT.md.
3. Map → pin → blast-radius read-only: status clean; map + pin
   recorded; early edit → revert.
4. Red-green + verify: test from task.md first; verbatim red,
   then green; reader re-runs; two-miss rule armed (hatch per 10);
   green-without-red → trap check per 09.
5. Commit + receipt: 1-file diff read line-by-line; RECEIPT.md
   (line, branch, map, pin, blast-radius, red/green, ledger-style
   rows for claims, handoff note); unlogged claim → cut or row.
